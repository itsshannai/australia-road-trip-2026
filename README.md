# 向西，再向南｜澳大利亚自驾旅行 2026

2026 年 9 月 23 日至 10 月 11 日的西澳与塔斯马尼亚自驾行程单页网站。

## 本地预览

这是一个无构建依赖的静态网站。直接打开 `index.html` 即可，或在目录中启动任意静态文件服务器。

## GitHub Pages

仓库设置中进入 **Settings → Pages**，选择 **Deploy from a branch**，分支选择 `main`、目录选择 `/ (root)`。

## 内容

- 19 天完整日程与阶段筛选
- 每日里程、驾驶时间、出发窗口、时间轴与延误预案
- 沿路餐厅、无人机建议与住宿分布
- 根据确认单整理的每日“住宿与预订”：酒店、床型、导航地址、入住与退改信息
- 10 份住宿单覆盖 12 晚；六晚缺单据明确标注，Rottnest Express 往返已对齐实际船票
- 72 项分组行前清单，可在本机持续保存完成状态
- 打印 / 保存 PDF 样式
- 响应式移动端布局

## 预订资料

`bookings.js` 只包含供公开行程使用的摘录。原始 PDF、住客姓名、邮箱、预订号码、PIN 和支付标识不放入仓库。未列时刻或设施不推断为已确认；更新确认单时应一并检查每日时间轴、住宿表和地图。原“票据夹”入口已移除，旧 `#documents` 链接转到住宿页；没有清除浏览器里原先保存的数据。

页面图片来自 Wikimedia Commons，作者与许可证均列于网页页脚。图片通过 Commons 的公开重定向地址加载，仓库不重新分发原始图片文件。
